# Niraj Kumar Singh — Architecture Portfolio

## Publish on GitHub Pages
1. Create a public repository named `nirajsingh-k.github.io`.
2. Upload the contents of this folder to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. The site will publish at `https://nirajsingh-k.github.io`.

Add your verified LinkedIn and resume URLs before finalizing.
